# 3. Schulbezogene Kataloge pflegen

Die "Schulbezogenen Katlaoge" finden sich unter dem Karteireiter "Kataloge". Während die Zuordnung der Ankreuzzeugnisse, der Fächerkatalog und die Stundentafeln in der Regel nur einmalig eingerichtet werden müssen, erfolgt die Einrichtung der Kurse ggf. jährlich bzw. halbjährlich.
### 3.1 [Klassen-/Versetzungstabelle](https://schulverwaltungsinfos.nrw.de/svws/wiki/index.php?title=Unterrichtsf%C3%A4cher_(Schulbezogene_Kataloge))  

**Aufgabe 1**  
Ermöglichen Sie Ankreuzzeugnisse im Jahrgang 3, indem Sie über "Kataloge" → "Klassen-/Versetzungstabelle" das entsprechende Kreuzchen setzen. 

Übernehmen Sie anschließend die aktuellen Angaben in die Schülerdaten.

### 3.2 [Fächer](https://schulverwaltungsinfos.nrw.de/svws/wiki/index.php?title=Unterrichtsf%C3%A4cher_(Schulbezogene_Kataloge))  

**Aufgabe 1**  
Ändern Sie die Sichtbarkeit für alle Fächer, die an Ihrer Schule nicht unterrichtet werden und blenden Sie sie aus. 


 
**Aufgabe 2**  
 Überprüfen Sie, ob die [Basisfächer](https://schulverwaltungsinfos.nrw.de/svws/wiki/index.php?title=Grundschulzeugnisse_Vorbereitung_f%C3%BCr_Text-_und_Ankreuzzeugnisse_(Tutorial)#Basisf%C3%A4cher)  im Fächerkatalog vorhanden sind, und ergänzen Sie sie bei Bedarf.
  
 Sortieren Sie die Sprachfächer, bzw. Deutschfächer in der Reihenfolge: Deutsch, Lesen, Rechtschreiben, Sprachgebrauch.
 
 **Aufgabe 3**  
 Legen Sie eine *Schwimm-AG* und das Fach *Islamischer Religionsunterricht* an.



### 3.3 [Stundentafeln](https://schulverwaltungsinfos.nrw.de/svws/wiki/index.php?title=Stundentafel_(Schulbezogene_Kataloge))
Nachdem der Fächerkatalog eingerichtet ist, können Stundentafeln eingerichtet werden. Eine Stundentafel ist eine Teilmenge der vorhandenen Fächer, die unter einem Namen zusammengefasst werden und die Unterricht beschreiben, der z.B. in einem Jahrgang gegeben wird.

Da sich die Zusammensetzung des Unterrichts nur selten ändert, müssen die Stundentafeln in der Regel nur einmal angelegt werden.

Sollte sich die Zusammensetzung des Unterrichts jährlich ändern, ist es sinnvoll, einmal alle vorhandenen (alten) Stundentafeln zu löschen. Damit wird die Übernahme von "Altlasten" zu verhindert.
#### 3.3.1 Stundentafeln anpassen  

**Aufgabe 1**

Erzeugen Sie unter Kataloge eine Stundentafel, wie sie an Ihrer Schule vorkommen kann.

**Aufgabe 2**  

Erzeugen Sie für den Jahrgang 3 eine Stundentafel, die dem Jahrgang 2 entspricht. Ergänzen Sie anschließend das Fach „Englisch“.

**Hinweis:**

Das Fach [Religion](https://schulverwaltungsinfos.nrw.de/svws/wiki/index.php?title=Grundschulzeugnisse_Vorbereitung_f%C3%BCr_Text-_und_Ankreuzzeugnisse_(Tutorial)#Sonderfall_Religion) nimmt bei den Stundentafeln eine Sonderrolle ein. Im folgenden Kapitel wird auch noch die Einrichtung über Kurse behandelt.
