# API Examples

Eine Einführung in die Nutzung der API befindet sich in der [SVWS-Dokumentation](https://doku.svws-nrw.de/development/API/).

Eine graphische Oberfläche der SVWS-API, die sogenannte SwaggerUI,  kann bei jedem SVWS-Server unter `https://SVWS-Server-URL/debug` erreicht werden.

Hier wird an einzelnen Beispielen der Unterschied zwischen Server API,Externe API, Privilege API erläuzert und für welche Benutzergruppen dies gedacht ist.

::: Tipp Berechtigungen beachten
Bitte bei der Benutzung der unterschiedlichen API-Endpunkte darauf achten, dass je nach Endpunkt hier unterschiedliche  Benutzer (Admin,root, Schulleitung, Lehrkraft, ... ) notwendig sind - siehe: [SVWS-Dokumentation](https://doku.svws-nrw.de/development/API/).
:::
