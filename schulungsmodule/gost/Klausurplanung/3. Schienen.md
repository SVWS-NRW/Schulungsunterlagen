# 3. Schienen – Klausuren blocken

Im Tab **Schienen** finden Sie die Auflistung der im gewählten Abschnitt anzusetzenden Klausuren. Hier legen Sie fest, welche Kurse gemeinsam an einem Termin schreiben.

:information_source: [Doku: Klausurtermine blocken](https://doku.svws-nrw.de/svws-client/apps/gost/klausurplanung/#klausurtermine-blocken)

Gehen Sie in dieser Reihenfolge vor:

1. Klausuren **aus Vorlage erstellen**
2. Termine selbst blocken (**Termin hinzufügen**) oder **automatisch blocken**

## Termine manuell setzen

**Termin hinzufügen** gibt die Möglichkeit, Kursgruppen zu gemeinsamen Terminen zusammenzufügen. Klausuren werden per Drag & Drop in die Termine gesetzt.

Es wird auf Kollisionen hingewiesen, wenn zwei Klausuren auf denselben Termin gesetzt werden und Schüler dadurch zeitgleich beide Klausuren schreiben müssten. Facharbeiten werden dabei nicht berücksichtigt.

:information_source: [Doku: Termin manuell setzen](https://doku.svws-nrw.de/svws-client/apps/gost/klausurplanung/#termin-manuell-setzen)

## Termine automatisch blocken

**Automatisch blocken** setzt in möglichst wenigen Terminen kollisionsfreie Kursklausurgruppen. Die Doku empfiehlt dieses Vorgehen.

::: tip Hinweise
- Sie können die Funktion **„Automatisch blocken“** hintereinander mit verschiedenen Einstellungen ausführen („Weiterblocken“).
- Sie können einzelne Termine zunächst selbst hinzufügen und die restlichen Klausuren automatisch blocken.
- Nach der Berechnung können einzelne Kurse in andere Termine verschoben werden. Schülerkollisionen werden automatisch angezeigt.
:::

:information_source: [Doku: Termine automatisch blocken](https://doku.svws-nrw.de/svws-client/apps/gost/klausurplanung/#termine-automatisch-blocken-ist-zu-bevorzugen)

::: info 📝 Aufgabe 3.1 „Klausuren erstellen“
1. Wechseln Sie für den gewählten Abiturjahrgang und Abschnitt in den Tab **Schienen**.
2. Erstellen Sie die Klausuren **aus der Vorlage**.
3. Kontrollieren Sie die Liste der anzusetzenden Klausuren.
:::

::: info 📝 Aufgabe 3.2 „Termine blocken“
Nutzen Sie nacheinander die verschiedenen Möglichkeiten. Verwerfen Sie die Ergebnisse jeweils, bevor Sie die nächste Variante testen:

1. nach **Schienen** blocken
2. nach **Fächern** blocken
3. getrennt nach **LK (schienenweise)** und **GK (fächerweise)** blocken: zuerst die LKs, dann mit „Weiterblocken“ und der Einstellung „GK + Fächerweise“ die Grundkurse
4. in **Q2.2 Halbjahr** nach Abiturfächern blocken (LK-Schienen 1 und 2, AB3-Block)
5. in **Q2.2 Abitur** nach Fachterminierungen Termine setzen
:::

::: info 📝 Aufgabe 3.3 „Manuell nachsteuern“
1. Legen Sie mit **Termin hinzufügen** einen eigenen Termin an und ziehen Sie zwei Kurse hinein.
2. Blocken Sie die übrigen Klausuren automatisch.
3. Verschieben Sie einen Kurs in einen anderen Termin, sodass eine Kollision entsteht, und beobachten Sie die Anzeige.
:::

::: tip Hinweis
Beachten Sie die rechts stehenden Hinweise sowie den Reiter **„Fehler und Hinweise“**.
:::

:information_source: [Doku: Fehler und Hinweise](https://doku.svws-nrw.de/svws-client/apps/gost/klausurplanung/#fehler-und-hinweise)
