# Aufgaben aus dem Alltag

**Aufgabe 1**

Korrigieren Sie einen fehlerhaften Familiennamen bei den Lernenden ausgewählter Klassen sowie bei den zugehörigen Erziehungsberechtigten.

**Aufgabe 2**

Erfassen Sie bei einer erziehungsberechtigten Person eine zusätzliche dienstliche Telefonnummer, unter der sie im Notfall erreichbar ist.

**Aufgabe 3**

Passen Sie die Daten einer lernenden Person und ihrer Erziehungsberechtigten an eine geänderte Familiensituation an. 
Die Erziehungsberechtigten leben getrennt, das gemeinsame Sorgerecht bleibt bestehen. 
Die lernende Person wohnt weiterhin bei einem Elternteil. 
Erfassen Sie für den anderen Elternteil eine neue Anschrift und eine neue Telefonnummer.

**Aufgabe 4**

Importieren Sie für einen Schülerdatensatz ein Foto aus dem Verzeichnis ..\SchuelerBilder.

**Hinweis:** Menü: [Weitere Funktionen](https://schulverwaltungsinfos.nrw.de/svws/wiki/index.php?title=Individualdaten_I_(Sch%C3%BCler)#Weitere_Funktionen)

**Aufgabe 5**

Erfassen Sie bei einer lernenden Person die Abmeldung vom Religionsunterricht ab dem heutigen Tag. 
Filtern Sie anschließend alle Lernenden, die vom Religionsunterricht befreit sind.

**Aufgabe 6**

Ändern Sie die Art der Schülerbeförderung für eine ausgewählte Gruppe von Lernenden anhand eines geeigneten Auswahlkriteriums (z. B. FöS KM, Wohnort, …). 
Weisen Sie einer Gruppe von Lernenden die Beförderungsart "Sonderfahrt" zu. Achtung: Diese [Fahrschülerart](https://schulverwaltungsinfos.nrw.de/svws/wiki/index.php?title=Fahrsch%C3%BCler-Arten_(Allgemeine_Kataloge)) muss zunächst im Menü "Kataloge" angelegt werden.

**Aufgabe 7**

Ordnen Sie die Lernenden eines ausgewählten Jahrgangs anhand eines geeigneten Auswahlkriteriums auf zwei Klassen auf.
(Beispiele für Auswahlkriterien: Konfession, Halbtag/Ganztag)

**Aufgabe 8**

Erfassen Sie bei einer lernenden Person einen individuellen Vermerk zum Sozialverhalten, 
z. B.: *„Die lernende Person hat sich gut in die Klasse eingelebt. Sie ist hilfsbereit und freundlich.“*

**Aufgabe 9**

Passen Sie die Anschriften und Kontaktdaten der Erziehungsberechtigten einer lernenden Person an. Hinterlegen Sie für beide Erziehungsberechtigten jeweils eine neue Adresse und eine neue Telefonnummer. 
Verwenden Sie hierfür frei gewählte Beispieladressen und Telefonnummern.

**Aufgabe 10**

Ordnen Sie einer lernenden Person eine Arbeitsgemeinschaft oder Personengruppe zu (z. B. Fußballmanschaft). 
Erstellen Sie anschließend eine neue Gruppe (z. B. Blockflöten-AG) und weisen Sie ihr mehrere Lernende zu.

**Aufgabe 11**

Übernehmen Sie eine lernende Person aus der *Aufnahme* in eine Klasse.

**Aufgabe 12**

Erfassen Sie bei einer lernenden Person das Ergebnis eines abgeschlossenen AO-SF-Verfahrens und hinterlegen Sie einen Hauptförderschwerpunkt.

**Aufgabe 13**

Bestimmen Sie je Klasse einen Bushelfer.

**Aufgabe 14**

Markieren Sie mehrere Lernende und erstellen Sie mithilfe eines geeigneten Gruppenprozesses einen Eintrag in der Wiedervorlageliste. 
Prüfen Sie anschließend unter „Verwaltung → Einstellungen → Globale Einstellungen → Allgemeines“, ob im Reiter „Wiedervorlage“ die entsprechende Option aktiviert ist. 
Starten Sie SchILD danach neu und kontrollieren Sie das Ergebnis.

**Aufgabe 15**

Erstellen Sie für eine beliebige Lehrkraft einen Eintrag in der Wiedervorlageliste und hinterlegen Sie einen Termin oder eine Aufgabe Ihrer Wahl.
