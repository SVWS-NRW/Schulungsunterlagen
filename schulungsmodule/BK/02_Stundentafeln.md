# 2 [Stundentafeln](https://schild3.svws-nrw.de/schild3/unterricht-kataloge/stundentafel-schulbezogene-kataloge.html)

Die Stundentafeln werden genutzt, um ganzen Klassen, Jahrgängen oder Schülergruppen auf einmal einen bestimmten Satz von Unterrichtsfächern zuzuordnen. 

***Präsentation**: Schulbezogene Kataloge --> Stundentafeln


## 2.1 Stundentafeln anpassen

**Aufgabe 1**
Erzeugen Sie unter Kataloge eine Stundentafel über das Plus Symbol, wie sie an Ihrer Schule vorkommen könnte – z.B. im Beruflichen Gymnasium Stufe 11, oder in einem Ihnen gut bekannten Berufsschul-Bildungsgang.

**Aufgabe 2** 
Stellen Sie bei "Sortierung" die Art auf **Benutzerdefiniert** und schieben Sie eine Stundentafel mithilfe der Pfeile weiter nach oben.
