# Klausurplanung

In diesem Modul planen Sie die Klausuren eines Abiturjahrgangs von den Vorgaben bis zum Nachschreibtermin. Sie arbeiten dabei in der **App Oberstufe ➜ Klausurplanung** des SVWS-Clients.

:information_source: [Doku: Klausurplanung (Übersicht)](https://doku.svws-nrw.de/svws-client/apps/gost/klausurplanung/)

## Voraussetzungen

Die Teilnehmenden können den SVWS-Client bedienen: Apps aufrufen, Schüler und Abiturjahrgänge auswählen, Lernabschnitte wechseln und Leistungsdaten einsehen. Diese Grundlagen werden in diesem Modul nicht mehr erklärt.

::: warning Stundenplan als Voraussetzung
Zur vollständigen Klausurplanung muss zur Terminierung unter **Stundenplan** eine Stundenplanperiode für die zu planenden Abschnitte eingerichtet werden.

- Dabei genügt die Anlage eines Stundenplanes. Eine exakte Verteilung der Stundenplanlagen ist für die Klausurplanung sehr hilfreich, aber nicht notwendig.
- **Ohne Stundenplan** können Sie immer noch **Klausuren blocken**, also festlegen, welche Kurse kollisionsfrei zusammen schreiben können.
- Setzen Sie im Stundenplan wenigstens das **Zeitraster**, dann sind auch Termine für Klausuren unabhängig von Unterrichtslagen setzbar.
:::

::: tip Raumliste
Für die Raumplanung (Kapitel 5) sollte eine vollständige **Raumliste** hinterlegt sein. Räume können auch über die Untis-Datei `GPU005.txt` importiert werden.
:::

:information_source: [Doku: Stundenplan](https://doku.svws-nrw.de/svws-client/apps/stundenplan/)  
:information_source: [Doku: Zeitraster](https://doku.svws-nrw.de/svws-client/apps/stundenplan/allgemeine_vorlagen/zeitraster/)  
:information_source: [Doku: Räume](https://doku.svws-nrw.de/svws-client/apps/stundenplan/allgemeine_vorlagen/raeume/)  
:information_source: [Doku: Raumdaten aus Untis importieren](https://doku.svws-nrw.de/svws-client/apps/schule/datenaustausch/untis/#raumdaten-importieren)

::: info 📝 Aufgabe 0.1 „Ausgangslage prüfen“
1. Prüfen Sie, ob für den zu planenden Abiturjahrgang im aktuellen Lernabschnitt ein **Stundenplan** vorliegt. Legen Sie andernfalls einen Stundenplan an und setzen Sie mindestens das **Zeitraster**.
2. Prüfen Sie, ob in den allgemeinen Vorlagen des Stundenplans eine **Raumliste** hinterlegt ist.
3. Notieren Sie, welche der folgenden Kapitel Sie mit Ihrem Datenstand vollständig bearbeiten können (Blocken geht immer, Kalender und Räume nur mit Stundenplan bzw. Raumliste).
:::
