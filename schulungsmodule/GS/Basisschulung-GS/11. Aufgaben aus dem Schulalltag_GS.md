# Aufgaben aus dem Alltag

**Aufgabe 1**

Korrigiere einen fehlerhaften Familiennamen bei den Lernenden ausgewählter Klassen sowie bei den zugehörigen Erziehungsberechtigten.

**Aufgabe 2**

Erfasse bei einer erziehungsberechtigten Person eine zusätzliche dienstliche Telefonnummer, unter der sie im Notfall erreichbar ist.

**Aufgabe 3**

Passe die Daten einer lernenden Person und ihrer Erziehungsberechtigten an eine geänderte Familiensituation an. 
Die Erziehungsberechtigten leben getrennt, das gemeinsame Sorgerecht bleibt bestehen. 
Die lernende Person wohnt weiterhin bei einem Elternteil. 
Erfasse für den anderen Elternteil eine neue Anschrift und eine neue Telefonnummer.

**Aufgabe 4**

Importiere für einen Schülerdatensatz ein Foto aus dem Verzeichnis ..\SchuelerBilder.

**Hinweis:** Menü: [Weitere Funktionen](https://schulverwaltungsinfos.nrw.de/svws/wiki/index.php?title=Individualdaten_I_(Sch%C3%BCler)#Weitere_Funktionen)

**Aufgabe 5**

Erfasse bei einer lernenden Person die Abmeldung vom Religionsunterricht ab dem heutigen Tag. 
Filtere anschließend alle Lernenden, die vom Religionsunterricht befreit sind.

**Aufgabe 6**

Ändere die Art der Schülerbeförderung für eine ausgewählte Gruppe von Lernenden anhand eines geeigneten Auswahlkriteriums (z. B. FöS KM, Wohnort, …). 
Weise einer Gruppe von Lernenden die Beförderungsart "Sonderfahrt" zu. Achtung: Diese [Fahrschülerart](https://schulverwaltungsinfos.nrw.de/svws/wiki/index.php?title=Fahrsch%C3%BCler-Arten_(Allgemeine_Kataloge)) muss zunächst im Menü "Kataloge" angelegt werden.

**Aufgabe 7**

Ordne die Lernenden eines ausgewählten Jahrgangs anhand eines geeigneten Auswahlkriteriums auf zwei Klassen auf.
(Beispiele für Auswahlkriterien: Konfession, Halbtag/Ganztag)

**Aufgabe 8**

Erfasse bei einer lernenden Person einen individuellen Vermerk zum Sozialverhalten, 
z. B.: *„Die lernende Person hat sich gut in die Klasse eingelebt. Sie ist hilfsbereit und freundlich.“*

**Aufgabe 9**

Passe die Anschriften und Kontaktdaten der Erziehungsberechtigten einer lernenden Person an. Hinterlege für beide Erziehungsberechtigten jeweils eine neue Adresse und eine neue Telefonnummer. 
Verwende hierfür frei gewählte Beispieladressen und Telefonnummern.

**Aufgabe 10**

Ordne einer lernenden Person eine Arbeitsgemeinschaft oder Personengruppe zu (z. B. Fußballmanschaft). 
Erstelle anschließend eine neue Gruppe (z. B. Blockflöten-AG) und weise ihr mehrere Lernende zu.

**Aufgabe 11**

Übernimm eine lernende Person aus der *Aufnahme* in eine Klasse.

**Aufgabe 12**

Erfasse bei einer lernenden Person das Ergebnis eines abgeschlossenen AO-SF-Verfahrens und hinterlege einen Hauptförderschwerpunkt.

**Aufgabe 13**

Bestimme je Klasse einen Bushelfer.

**Aufgabe 14**

Markiere mehrere Lernende und erstelle mithilfe eines geeigneten Gruppenprozesses einen Eintrag in der Wiedervorlageliste. 
Prüfe anschließend unter „Verwaltung → Einstellungen → Globale Einstellungen → Allgemeines“, ob im Reiter „Wiedervorlage“ die entsprechende Option aktiviert ist. 
Starte SchILD danach neu und kontrolliere das Ergebnis.

**Aufgabe 15**

Erstelle für eine beliebige Lehrkraft einen Eintrag in der Wiedervorlageliste und hinterlege einen Termin oder eine Aufgabe Deiner Wahl.
